# ELK Stack Training Lab

Lab training ELK Stack (Elasticsearch, Logstash, Kibana) — 4 hari, 8 sesi,
berbasis Docker.

## Mulai di Sini

Peserta baru: baca **[`docs/participant-quickstart.md`](docs/participant-quickstart.md)**
lebih dulu, lalu **[`docs/prerequisites.md`](docs/prerequisites.md)**.

## Kenapa Pelatihan Ini Penting

- Memahami ekosistem ELK Stack untuk pengelolaan, pencarian, analisis, dan visualisasi data.
- Meningkatkan kemampuan data indexing, document management, dan advanced searching menggunakan Elasticsearch.
- Mampu mengelola data ingestion dan data transformation menggunakan Logstash dan Beats.
- Meningkatkan kemampuan data analytics dan visualization menggunakan Aggregations dan Kibana.
- Memahami pengelolaan cluster, security, monitoring, backup, dan high availability pada Elasticsearch.
- Mempersiapkan peserta untuk menerapkan performance optimization, scaling, dan best practices pada lingkungan production.
